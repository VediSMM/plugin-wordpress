# Руководство VediSMM для WordPress

VediSMM для WordPress позволяет редакторам отправлять записи и страницы в VediSMM, не передавая API-токен в браузер.

## Настройка

1. Установите и активируйте плагин.
2. Откройте Settings -> VediSMM.
3. Вставьте API-токен из аккаунта VediSMM.
4. При последующих сохранениях оставьте поле токена пустым, чтобы сохранить текущий токен.

## Редакторский сценарий

- Создать черновик: отправляет текущий материал WordPress в VediSMM как черновик.
- Запланировать: сначала создаёт черновик, затем планирует его на выбранное время.
- Опубликовать: сначала создаёт черновик, затем ставит публикацию в очередь VediSMM.

Сохранение записи WordPress никогда не публикует материал автоматически.
Кнопка **Отправить в VediSMM** работает через штатный hook `save_post` после
проверки nonce и права `edit_post`. Два трекинговых флажка сохраняются и
восстанавливаются; обычное сохранение без явного нажатия этой кнопки не
вызывает API.

## Трекинговые ссылки

В блоке VediSMM есть флажки **Сокращать ссылки** и **Добавлять источник
площадки**. По умолчанию оба выключены. Источник доступен только при включённом
сокращении; выключение сокращения также снимает и блокирует флажок источника.
Плагин передаёт значения только внутри `options.tracking`, не переписывает URL
редактора и не хранит состояние созданных ссылок.

ВедиSMM создаёт отдельную короткую ссылку для каждой целевой площадки. При
включённом источнике, если непустой `utm_source` отсутствует, ВедиSMM добавляет
`utm_source=<network>` и сохраняет существующий `utm_term`. Если `utm_source`
уже есть, ВедиSMM сохраняет его, а все существующие `utm_term` заменяет (или
добавляет один) ровно одним `utm_term=<network>`. Остальные query-параметры,
encoded values, их порядок и fragment остаются без изменений.
